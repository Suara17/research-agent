# Agent 记忆机制分析与优化

## 一、当前实现架构

### 1.1 记忆类型

| 类型 | 存储方式 | 容量 | 用途 |
|------|----------|------|------|
| **短期记忆 (short)** | FIFO 队列 | 64条 | 存储最近的思考/工具输出 |
| **长期记忆 (long)** | TF-IDF 索引 | 1000条 | 存储历史搜索结果、页面内容 |

### 1.2 检索机制

采用 **BM25** 排序算法：
- 词项频率 (TF)
- 逆文档频率 (IDF)
- 文档长度归一化
- 时间衰减boost (2分钟内 1.5x, 5分钟内 1.2x)

### 1.3 注入方式

两处自动注入：

1. **agent_node** (第443行):
```python
mem_hits = memory.search(user_query, top_k=4)
# 插入 <memory_context> 到 system prompt
```

2. **memory_query 工具**:
```python
def memory_query(query: str, top_k: int = 5) -> str:
    hits = memory.search(query, top_k=top_k)
    return json.dumps({"results": hits}, ensure_ascii=False)
```

## 二、问题分析

### 2.1 短期记忆问题

| 问题 | 现状 | 影响 |
|------|------|------|
| 纯 FIFO 队列 | 只保留最新64条 | 旧的重要信息被丢弃 |
| 无语义理解 | 简单字符串列表 | 无法识别关键信息 |
| 无优先级 | 所有内容一视同仁 | 噪声淹没重点 |
| 无压缩 | 原始内容直接存储 | 浪费空间 |

### 2.2 长期记忆问题

| 问题 | 现状 | 影响 |
|------|------|------|
| 检索结果直接注入 | 不做过滤直接插入 | 不相关内容浪费 token |
| 无跨任务记忆 | 每个 session 独立 | 无法利用历史经验 |
| 缺乏记忆总结 | 原始内容存储 | 细节淹没要点 |
| 索引重建成本高 | 每次添加都重建 | 性能瓶颈 |

### 2.3 注入时机问题

| 问题 | 现状 | 影响 |
|------|------|------|
| 每次都注入 | 每轮 LLM 调用前 | token 快速增长 |
| 无差异化 | 简单/复杂问题同样处理 | 简单问题被记忆干扰 |
| 注入位置固定 | system prompt 靠后 | 优先级低 |

def add_short(self, item: str, importance: float = 0.5) -> None:

### 3.3 检索优化

#### 方案 5：相关性过滤 + 差异化注入

```python
def inject_memory_context(self, query: str, step: int, max_steps: int) -> str:
    """差异化记忆注入"""
    
    # 1. 计算问题复杂度
    complexity = assess_complexity(query)
    
    # 2. 根据复杂度选择注入策略
    if complexity == "simple":
        # 简单问题不注入，避免干扰
        return ""
    
    # 3. 检索并过滤
    hits = self.search(query, top_k=4)
    filtered = self.filter_irrelevant(hits, query)
    
    # 4. 只注入高相关度结果
    if filtered and filtered[0]["score"] > 0.5:
        return format_memory_context(filtered)
    
    return ""
```

#### 方案 6：记忆质量评分

```python
def filter_irrelevant(self, hits: list, query: str) -> list:
    """过滤不相关记忆"""
    filtered = []
    for hit in hits:
        # 检查是否有新信息
        if has_new_information(hit["text"], query):
            # 检查时间衰减
            if hit.get("age_days", 0) < 7:  # 7天内
                filtered.append(hit)
    return filtered
```

# memory.py search 方法中增加
def search(self, query: str, top_k: int = 3, min_score: float = 0.3) -> List[dict]:
    results = self._bm25_search(query, top_k)
    # 过滤低分结果
    return [r for r in results if r["score"] > min_score]
