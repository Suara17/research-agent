# 10分钟内增加推理搜索量 - 极限优化方案

## 目标
在10分钟(600秒)内，让Agent完成更多推理搜索，同时保证答案可靠性。

async def web_fetch_fast(url: str) -> str:
    # 并行尝试多个方法
    tasks = [
        jina_fetch(url),      # 最快
        trafilatura_fetch(url), 
    ]
    
    done = await asyncio.wait_for(asyncio.gather(*tasks), timeout=5)

# 抓取多个URL时并行
async def fetch_urls_parallel(urls: list) -> list:
    tasks = [web_fetch_fast(url) for url in urls[:3]]
    return await asyncio.gather(*tasks)

## 可靠性保障

在加速的同时，通过以下方式保障可靠性：

1. **强制验证表**：Final Answer必须有≥2个来源
2. **置信度阈值**：低于0.8必须继续搜索
3. **快速失败检测**：连续无进展自动换策略
4. **保留核心规则**：压缩但不删除关键指令
