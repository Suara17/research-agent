# Agent搜索步数强制至少30步 - 修改总结

## 用户期望目标

**目标**：强制Agent在验证集问题测试中至少搜索30步，而不是之前的12步就提前输出答案。

## 问题分析

1. **原问题**：Agent在12步左右就输出Final Answer，导致搜索深度不足
2. **原因**：
   - 候选验证计数逻辑失效（正则表达式不匹配实际格式）
   - 步数检查后没有强制继续搜索
   - Agent过早收敛到一个候选就输出答案

### 3. 修改should_continue逻辑 (`core.py:789-801`)

**目标**：即使Agent输出了Final Answer，如果没有达到30步也要强制继续

```python
def should_continue(state: AgentState) -> Literal["tools", "__end__"]:
    current_step = state.get("step_index", 0)
    max_steps = state.get("max_steps", 40)
    min_steps = 30
    force_continue = state.get("force_continue", False)
    pending = state.get("pending_tool_calls", [])

    # 如果强制继续标志为True，或者步数没达到最小值，继续搜索
    if force_continue or current_step < min_steps:
        return "tools"
    # 如果有pending_tool_calls，继续执行
    if pending:
        return "tools"
    # 如果达到最大步数，结束
    if current_step >= max_steps:
        return "__end__"
    return "__end__"
```
