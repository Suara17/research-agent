# Windows Terminal 使用技巧

本文档总结了Windows Terminal的各种使用技巧，包括窗口分割、关闭窗口、多开窗口等操作方法。

## 窗口分割

### 分割快捷键
- **垂直分割**：`Ctrl + Shift + D`
- **水平分割**：`Ctrl + Shift + R`

### 通过命令面板分割
1. 按 `Ctrl + Shift + P` 打开命令面板
2. 输入 "split" 即可查看所有分屏相关命令
3. 选择相应的分割选项

### 自定义分割快捷键
在某些自定义配置中：
- `Ctrl + E`：向下分屏
- `Ctrl + D`：向右分屏

## 关闭窗口和窗格

### 关闭窗格
- **关闭焦点窗格**：`Ctrl + Shift + W`
- 如果只有一个窗格，`Ctrl + Shift + W` 将关闭该标签页

### 关闭窗口
- **关闭当前窗口**：`Alt + F4`
- **关闭活动窗格或标签页**：`Alt + Shift + W` 或在终端中输入 `exit` 命令

## 调整窗格大小

- **调整窗格大小**：`Alt + Shift + 方向键`
- 使用方向键可以相应地调整窗格的大小

## 多窗口管理

Windows Terminal支持多标签页管理，可以通过以下方式操作：
- 创建新的标签页
- 在不同标签页间切换
- 管理多个终端会话

## 其他实用技巧

- **打开命令面板**：`Ctrl + Shift + P`
- **复制文本**：`Ctrl + C` 或 `Ctrl + Shift + C`
- **粘贴文本**：`Ctrl + V` 或 `Ctrl + Shift + V`
- **新建标签页**：`Ctrl + Shift + T`
- **关闭标签页**：`Ctrl + Shift + W`

## 自定义配置

您可以在Windows Terminal的设置中自定义快捷键和行为。编辑 `settings.json` 文件可以实现更个性化的配置。

## 总结

Windows Terminal提供了丰富的窗口管理和操作功能，熟练掌握这些快捷键和技巧可以显著提高工作效率。通过合理的窗口分割和管理，您可以同时运行多个终端会话，满足复杂的开发需求。
