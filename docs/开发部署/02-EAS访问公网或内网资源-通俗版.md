# EAS 服务网络配置：通俗指南

> 这篇文档将帮助你理解如何让 EAS 服务访问公网或内网资源

---

## 1. 先搞懂基本概念

### 1.1 EAS 服务是什么？

**EAS（Elastic Algorithm Service）** 是阿里云 PAI 平台提供的推理服务部署工具。

你可以把 EAS 想象成一个**运行代码的"容器"**。但默认情况下，这个容器是"封闭"的，无法访问外部网络。

### 1.2 为什么要配置网络？

默认的 EAS 服务：
- ❌ 无法访问公网（如调用外部 API、下载文件）
- ❌ 无法访问其他阿里云服务（如 RDS 数据库、OSS）

配置网络后：
- ✅ 可以访问公网
- ✅ 可以与同 VPC 内的其他服务互通

---

## 2. 整体架构是怎样的？

### 场景一：内网互通

```
┌─────────────────────────────────────────────────┐
│                   VPC（专有网络）                 │
│                                                 │
│   ┌─────────────┐        ┌─────────────┐       │
│   │  EAS 服务   │ <----> │  目标服务   │       │
│   │ (有ENI网卡) │        │ (RDS/OSS等) │       │
│   └─────────────┘        └─────────────┘       │
│                                                 │
└─────────────────────────────────────────────────┘
```

**适用场景**：EAS 和目标服务在同一个 VPC 内

### 场景二：公网访问

```
┌──────────────────────────────────────────────────────────┐
│                      VPC（专有网络）                       │
│                                                          │
│   ┌─────────────┐                                       │
│   │  EAS 服务   │                                       │
│   │ (有ENI网卡) │                                       │
│   └──────┬──────┘                                       │
│          │                                              │
│          ▼                                              │
│   ┌─────────────┐      ┌─────────────┐                 │
│   │ NAT 网关    │ ───> │ 弹性公网IP  │ ──> 公网(Internet)│
│   │ (出口网关)   │      │   (EIP)    │                 │
│   └─────────────┘      └─────────────┘                 │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

## 3. 核心组件介绍

### 3.1 VPC（专有网络）

**通俗理解**：VPC 就像你在云上的一片"私人领地"。

- 完全与其他人隔离
- 你可以自己定义网络规则
- 创建一个 VPC 需要指定一个网段（如 `10.0.0.0/16`）

### 3.2 交换机（vSwitch）

**通俗理解**：交换机是 VPC 内的"分区"或"子网"。

- 一个 VPC 可以有多个交换机
- 同一 VPC 内的交换机之间可以互通
- 交换机必须放在某个**可用区**（AZ）里

**可用区（AZ）**：同一个城市内的不同物理机房。一个可用区故障，其他可用区不受影响。

### 3.3 ENI（弹性网卡）

**通俗理解**：ENI 就是 EAS 服务的"网络身份证"。

- 配置 VPC 后，EAS 每个实例都会获得一个 ENI
- ENI 会占用交换机的一个 IP 地址
- 有了 ENI，EAS 才能在 VPC 中通信

### 3.4 NAT 网关

**通俗理解**：NAT 网关是 VPC 的"出口大门"。

- 让 VPC 内的服务可以访问公网
- 隐藏内部 IP 地址（对外只显示 EIP）
- **这是付费服务！**

### 3.5 EIP（弹性公网 IP）

**通俗理解**：EIP 就是"公网门牌号"。

- 一个固定的公网 IP 地址
- 绑定到 NAT 网关，作为访问公网的出口
- **这是付费服务！**

## 4. 操作步骤

### 步骤总览

```
开始
  │
  ├─ 确认需求
  │    │
  │    ├─ 只需内网互通 ─────> 步骤1 → 完成
  │    │
  │    └─ 需要访问公网 ────> 步骤1 → 步骤2 → 完成
  │
  └─ 准备 VPC 和交换机（如果还没有）
```

### 步骤 1：配置 VPC（内网互通的基础）

#### 方式一：通过控制台配置

1. 创建或更新 EAS 服务
2. 在"网络信息"区域，选择专有网络
3. 选择交换机和安全组

#### 方式二：通过命令行工具（eascmd）

在 JSON 配置中添加：

```json
{
  "cloud": {
    "networking": {
      "vpc_id": "vpc-xxxxx",
      "vswitch_id": "vsw-xxxxx",
      "security_group_id": "sg-xxxxx"
    }
  }
}
```

**参数说明**：

| 参数 | 怎么找？ |
|------|---------|
| vpc_id | 阿里云 VPC 控制台 → 专有网络 |
| vswitch_id | 阿里云 VPC 控制台 → 交换机 |
| security_group_id | 阿里云 ECS 控制台 → 安全组 |

#### 配置级别说明

| 级别 | 优先级 | 说明 |
|------|--------|------|
| 服务级别 | 高 | 为单个服务指定 VPC |
| 资源组级别 | 低 | 为整个资源组设置默认 VPC |

**注意**：如果两个都配置了，以服务级别为准。

---

### 步骤 2：配置公网访问（仅当需要访问公网时）

#### 2.1 创建 NAT 网关并绑定 EIP

1. 打开 [NAT 网关购买页](https://vpc.console.aliyun.com/buy/nat)
2. 选择 EAS 所在的地域
3. 选择 EAS 所在的 VPC
4. 购买并绑定一个 EIP

#### 2.2 配置 SNAT 条目

SNAT 的作用：让 VPC 内的服务可以访问公网

1. 进入 NAT 网关页面
2. 创建 SNAT 条目
3. 选择"VPC 粒度"

```
配置示例：
- SNAT 条目粒度：VPC
- VPC：选择 EAS 所在的 VPC
```

## 5. 重要补充：配置白名单

如果目标服务有 IP 白名单，需要把 EAS 的 IP 加进去。

### 获取 EAS 的内网 IP

**重要**：EAS 实例是动态的，IP 可能会变！

**正确做法**：使用**交换机网段**，不要写死单个 IP。

查询方法：
1. 打开 [VPC 控制台](https://vpc.console.aliyun.com/)
2. 进入"交换机"页面
3. 查看交换机的 IPv4 网段（如 `10.0.1.0/24`）

### 获取 EAS 的公网 IP

如果配置了 NAT 网关：
1. 打开 [VPC 控制台](https://vpc.console.aliyun.com/)
2. 进入"NAT 网关"页面
3. 查看绑定的 EIP

## 7. 常见问题

### Q1：为什么 EAS 默认不能访问公网？

**原因**：
- 公网带宽是共享的，容易被滥用
- 带宽不稳定，影响服务性能

**解决**：需要手动配置 VPC + NAT 网关

---

### Q2：如何验证公网是否连通？

在 EAS 服务的启动命令中添加测试：

```bash
curl -I -A "Mozilla/5.0" --connect-timeout 5 https://www.aliyun.com
```

部署后查看日志，如果返回 `200`，说明公网正常。

---

### Q3：配置了 VPC 还是无法内网访问？

排查顺序：

1. **检查 VPC**：确认 EAS 和目标服务在同一个 VPC
2. **检查安全组**：确认安全组出方向允许访问目标服务
3. **检查白名单**：确认目标服务已添加 EAS 所在交换机的网段

---

### Q4：配置了 NAT 网关还是无法访问公网？

排查顺序：

1. **检查 SNAT**：确认 SNAT 条目中的交换机与 EAS 使用的一致
2. **检查路由表**：确认存在 `0.0.0.0/0` 指向 NAT 网关的路由
3. **检查安全组**：确认出方向允许公网访问

## 8. 最佳实践

### 1. IP 地址规划

为 EAS 分配一个**独立的交换机**，IP 数量要充足。

计算公式：
```
所需IP = 稳定运行实例数 + 滚动更新额外实例数 + 预留缓冲
```

### 2. 安全组隔离

- 不同环境（开发/测试/生产）使用不同安全组
- 遵循最小权限原则

### 3. 成本优化

- 同地域资源优先使用内网通信
- 公网访问尽量走 NAT 网关（固定 IP，方便管理白名单）
