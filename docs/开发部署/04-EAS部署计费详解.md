# EAS 服务部署计费详解指南

本文档详细介绍将 Agent 应用部署为 EAS 服务过程中涉及的各项费用，帮助您全面了解成本构成，实现成本优化。

## 计费概述

在部署 EAS 服务时，您可能需要为以下几类资源付费：

| 资源类型 | 是否必需 | 计费方式 | 说明 |
|----------|----------|----------|------|
| EAS 计算资源 | 是 | 按量付费 / 包年包月 | 核心费用 |
| 系统盘 | 可选 | 按量付费 / 包年包月 | 有免费额度 |
| 专属网关 | 可选 | 按量付费 / 包年包月 | 默认免费 |
| NAT 网关 | 可选 | 按量付费 | 公网访问必需 |
| 弹性公网 IP（EIP） | 可选 | 按量付费 / 包年包月 | NAT 网关必需 |
| VPC | 否 | 免费 | 阿里云提供免费额度 |

> **重要提示**：如果您使用了弹性公网、OSS、NAS 等其他阿里云服务，将产生归属于其他云服务的费用。

## EAS 计算资源计费详解

### 计费模式

EAS 提供两种计费模式，您可以根据业务需求选择：

| 计费模式 | 说明 | 适用场景 |
|----------|------|----------|
| **按量付费** | 根据服务运行时长计费，按分钟计算 | 测试环境、需求波动大的业务 |
| **包年包月** | 先付费再使用，享受更优惠价格 | 长期稳定使用的生产环境 |

> **计费关键点**：按量付费模式下，只要服务处于「运行中」状态就会持续计费，即使没有任何请求也会收费。因此，测试完成后请务必**及时停止服务**。

### 资源类型

EAS 计算资源分为三种类型：

| 资源类型 | 说明 | 特点 |
|----------|------|------|
| **公共资源** | 共享阿里云资源池，按需使用 | 成本低，但资源不保证供给 |
| **专属资源** | 独享硬件资源，性能稳定 | 成本高，适合生产环境 |
| **灵骏智算资源** | 大规模深度学习场景 | 支持分布式训练 |

### 按量付费定价

#### 方式一：指定机器资源

根据 CPU 和内存的实际使用量计费：

```
账单金额 = 实例数 × (CPU核数 × CPU单价 + 内存GB数 × 内存单价) × 使用时长(分钟)
```

**参考单价（以控制台实际价格为准）**：

| 资源类型 | 单价 |
|----------|------|
| CPU | 0.194 元/核/小时 |
| 内存 | 0.024 元/GB/小时 |

**计算示例**：

假设您使用 2 个 CPU 核心 + 8 GB 内存的实例，运行 1 小时：

```
账单金额 = 2 × (2 × 0.194 + 8 × 0.024) × 1 = 2 × (0.388 + 0.192) = 1.16 元
```

#### 方式二：指定机器型号

直接选择预设的实例规格，按规格单价计费：

```
账单金额 = 实例数 × 实例规格单价 × 使用时长(分钟)
```

**常见 GPU 实例规格（仅供参考，实际价格以控制台为准）**：

| 实例规格 | vCPU | 内存 | GPU | 显存 |
|----------|------|------|-----|------|
| ecs.g7.xlarge | 4 核 | 16 GB | 1 × T4 | 16 GB |
| ecs.g7.2xlarge | 8 核 | 32 GB | 1 × T4 | 16 GB |
| ecs.gn7i-c16g1.4xlarge | 16 核 | 60 GB | 1 × A10 | 24 GB |
| ml.gu7i.c32m188.1-gu30 | 32 核 | 188 GB | 1 × L20 | 24 GB |

### 包年包月定价

包年包月需要提前购买一定时长的资源：

```
账单金额 = 机器规格数量 × 单价 × 购买时长(月)
```

**示例**：

假设您购买 2 台 ecs.g6.6xlarge（24 核 CPU + 96 GB 内存）机器，购买 3 个月，单价为 3683 元/月：

```
总金额 = 2 × 3683 × 3 = 22098 元
```

### 计费开始与结束时间

#### 按量付费

| 资源类型 | 计费开始时间 | 计费结束时间 |
|----------|--------------|--------------|
| 公共资源 | 服务进入「运行中」状态 | 服务停止或释放 |
| 专属资源 | 机器创建成功并进入运行状态 | 机器被删除或处于已停机状态 |

> **关键提醒**：公共资源一旦部署成功就开始计费，即使不调用也会收费。请务必在测试完成后停止服务！

#### 包年包月

| 资源类型 | 计费开始时间 | 计费结束时间 |
|----------|--------------|--------------|
| 专属资源 | 购买次日 00:00:00 | 到期时间 |
| 灵骏智算资源 | 购买次日 00:00:00 | 到期时间 |

### 服务扩缩容计费

| 操作 | 计费规则 |
|------|----------|
| **扩容** | 新资源从扩容成功的时间开始计费 |
| **缩容** | 释放的资源从释放成功的时间停止计费，剩余资源继续计费 |

## 系统盘计费详解

### 免费额度

| 资源类型 | 免费额度 |
|----------|----------|
| 公共资源 | 30 GB |
| 专属资源 | 200 GB |

### 超出免费额度计费

```
账单金额 = 实例数 × 超出容量(GB) × 单价 × 使用时长(分钟)
```

**单价参考**：约 0.0021 元/GB/小时（具体以 ESSD 云盘 PL1 定价为准）

### 计费示例

**场景一**：使用公共资源，每台机器系统盘 300 GB，使用 5 小时

- 免费额度：30 GB
- 超出容量：300 - 30 = 270 GB

```
账单金额 = 2 × 270 × 0.0021 × 5 = 5.67 元
```

**场景二**：使用专属资源包年包月，每台机器系统盘 300 GB，购买 3 个月

- 免费额度：200 GB
- 超出容量：300 - 200 = 100 GB

```
账单金额 = 2 × 100 × 3 = 600 元
```

## 专属网关计费详解

### 默认配置

- 部署服务时**默认使用共享网关**，完全**免费**
- 共享网关适合一般业务需求

### 何时需要专属网关？

如果您有以下需求，可以付费购买专属网关：

| 需求场景 | 说明 |
|----------|------|
| 安全隔离 | 需要与其他用户完全隔离 |
| 访问控制 | 需要精细化配置访问策略 |
| 自定义域名 | 需要绑定自己的域名 |
| 独立带宽 | 需要独立的网络带宽 |

### 计费方式

| 计费模式 | 计费公式 |
|----------|----------|
| 按量付费 | 账单金额 = (网关单价 / 60) × 网关节点数量 × 运行时长(分钟) |
| 包年包月 | 账单金额 = 网关单价 × 网关节点数量 × 购买时长(月) |

## NAT 网关计费详解

### 为什么需要 NAT 网关？

EAS 服务默认无法访问公网。如果您的 Agent 应用需要调用阿里云百炼等公网服务，必须配置 NAT 网关来实现公网访问。

### 计费组成

NAT 网关费用由两部分组成：

| 计费项 | 说明 |
|--------|------|
| **实例费** | NAT 网关实例本身的费用，按小时计费 |
| **容量单位（CU）费** | 根据处理流量计费 |

### 计费公式

```
总费用 = 实例费 + CU 费

实例费 = 实例单价(元/小时) × 使用时长(小时)
CU 费 = CU 单价(元/个) × 处理流量 CU 个数
处理流量 CU 个数 = 总处理流量(GB) / 1 GB
```

### 定价参考（华东1 杭州地域）

| 计费项 | 单价 |
|--------|------|
| 实例费 | 0.23 元/小时 |
| CU 费 | 0.23 元/个/小时 |

### 计费示例

**场景**：创建 1 个 NAT 网关，处理流量 10 GB，使用 2 小时

```
实例费 = 0.23 × 2 = 0.46 元
CU 费 = 0.23 × 10 = 2.30 元
总费用 = 0.46 + 2.30 = 2.76 元
```

### 重要说明

- **按量付费**：NAT 网关仅支持按量付费，不支持包年包月
- **计费周期**：每 1 小时计费一次，不足 1 小时按 1 小时计费
- **停止计费**：删除 NAT 网关实例后停止计费

## 弹性公网 IP（EIP）计费详解

### 为什么需要 EIP？

NAT 网关需要绑定 EIP 才能访问公网。EIP 是独立的计费项。

### 计费方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **按使用流量计费** | 按实际流量收费 | 流量波动大、难以预估 |
| **按固定带宽计费** | 按带宽峰值收费 | 流量稳定 |
| **包年包月** | 预付费 | 长期使用，价格更优惠 |

### 按量付费定价

#### 按使用流量计费

```
账单金额 = 流量费 + 配置费
流量费 = 实际使用流量(GB) × 单价
配置费 = IP 保有费(如有)
```

> **注意**：流量费仅计算**出方向流量**（从阿里云到互联网），入方向流量免费。

#### 按固定带宽计费

```
账单金额 = 带宽费 + 配置费
带宽费 = 带宽峰值(Mbps) × 单价 × 时长
```

**带宽单价参考**：

| 带宽 | 单价（元/月） |
|------|--------------|
| 1 Mbps | 20 元 |
| 3 Mbps | 50 元 |
| 5 Mbps | 80 元 |
| 10 Mbps | 150 元 |

> 具体价格以控制台购买页为准。

### 包年包月定价

```
账单金额 = 带宽费 × 购买时长
```

### EIP 配置费说明

| 情况 | 是否收取配置费 |
|------|----------------|
| EIP 绑定至 VPC 类型的 ECS 实例，账号下 EIP 数量 ≤ 2000 | 不收取 |
| 从 IP 地址池分配的 EIP | 不收取 |
| 其他情况 | 收取 |

## 综合计费示例

### 场景描述

假设您部署一个 Agent 应用到 EAS 服务，配置如下：

- **EAS 服务**：使用公共资源，按量付费
  - 实例规格：2 核 CPU + 8 GB 内存
  - 运行时间：每天 8 小时（测试 30 天）
- **系统盘**：100 GB（超出免费额度 70 GB）
- **NAT 网关**：1 个
- **EIP**：按固定带宽 5 Mbps 包年包月

### 费用计算

#### 1. EAS 计算资源费用

```
按量付费单价：CPU 0.194元/核/小时 + 内存 0.024元/GB/小时
每小时费用 = 2 × 0.194 + 8 × 0.024 = 0.388 + 0.192 = 0.58 元
30天费用 = 0.58 × 8 × 30 = 139.2 元
```

#### 2. 系统盘费用

```
超出容量 = 100 - 30 = 70 GB
单价 ≈ 0.0021 元/GB/小时
费用 = 70 × 0.0021 × 8 × 30 = 35.28 元
```

#### 3. NAT 网关费用（按量付费）

```
实例费 = 0.23 元/小时 × 8 小时/天 × 30 天 = 55.2 元
假设每月流量 100 GB：CU费 = 0.23 × 100 = 23 元
NAT网关月费 ≈ 78.2 元
```

#### 4. EIP 费用（包年包月）

```
5 Mbps 带宽 ≈ 80 元/月
年费 = 80 × 12 = 960 元
```

#### 5. 总费用估算

| 项目 | 月费用（元） |
|------|-------------|
| EAS 计算资源 | 139.2 |
| 系统盘 | 35.28 |
| NAT 网关 | 78.2 |
| EIP（月均） | 80 |
| **合计** | **约 332.68 元/月** |

> **注意**：以上仅为估算示例，实际费用以阿里云账单为准。

## 成本优化建议

### 1. 及时停止服务

> **最重要的一点**：按量付费模式下，只要服务运行就会收费。测试完成后务必停止服务！

在 EAS 控制台的服务列表中，点击「停止」按钮即可停止计费。

### 2. 选择合适的计费模式

| 场景 | 推荐模式 |
|------|----------|
| 短期测试 | 按量付费 |
| 长期稳定业务 | 包年包月 |
| 流量波动大 | 按量付费 + 节省计划 |

### 3. 使用节省计划

节省计划可以享受按量付费的折扣优惠：

- 承诺一定周期内的消费金额
- 可抵扣公共资源费用
- 适合有一定使用量的用户

### 4. 公网流量优化

如果需要从公网下载模型或文件：

- **最佳方案**：将资源上传至同地域的 OSS
- 部署时直接挂载 OSS，避免公网流量费用

### 5. 选择合适的实例规格

根据实际需求选择：

- CPU 推理：选择 CPU 实例即可
- GPU 推理：根据模型复杂度选择合适显存
- 避免过度配置，浪费资源

### 6. 使用 Serverless 版（限特定场景）

对于 SDWebUI 和 ComfyUI，EAS 提供 Serverless 版本：

- 部署完全免费
- 仅按实际推理时长计费
- 适合调用频率不高的场景

## 欠费与停机说明

### 按量付费资源

当账户余额不足时：

1. **延期免停权益**：欠费后一定时间内仍可正常使用
2. **实例锁定**：超出延停额度后，实例被锁定，服务停止，计费停止
3. **实例删除**：7 天内未充值补足欠费，实例被删除

### 包年包月资源

- 到期后会自动停止服务
- 有一定宽限期可以续费
- 到期未续费，资源会被释放

| 术语 | 解释 |

| 按量付费 | 先使用后付费，根据实际用量计费 |
