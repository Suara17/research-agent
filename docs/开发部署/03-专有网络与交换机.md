# 专有网络与交换机详解

> 来源：https://help.aliyun.com/zh/vpc/vpc-and-vswitch

本文详细介绍阿里云专有网络 VPC 和交换机 vSwitch 的概念、创建和管理方法，帮助新手理解云上网络架构。

---

## 什么是专有网络（VPC）？

### 基本概念

**专有网络 VPC（Virtual Private Cloud）** 是阿里云提供的专有的云上私有网络。

你可以完全掌控自己的专有网络，包括：
- 自定义网络拓扑和 IP 地址范围
- 配置路由策略
- 设置安全组规则

### VPC 的特性

| 特性 | 说明 |
|------|------|
| 地域级别 | VPC 是地域级别的资源，在一个地域内创建 |
| 私有性 | 与其他 VPC 完全隔离 |
| 可控性 | 用户完全掌控网络配置 |
| 灵活性 | 可灵活划分网段、配置路由 |

> **通俗理解**：VPC 就像你在云上自己的一片"领地"，你可以在里面自由规划和建设你的网络"城市"。

---

## 什么是交换机（vSwitch）？

### 基本概念

**交换机 vSwitch** 是可用区级别的资源，可以将 VPC 划分成多个子网。

- 同一 VPC 内的不同交换机之间**内网互通**
- 通过在多个不同可用区的交换机中部署资源，可以**避免单点故障**

### 可用区（AZ）说明

可用区是同一地域内电力和网络互相独立的物理区域。在同一地域内，多个可用区之间内网互通，但**可用区之间的故障是相互隔离的**。

> **通俗理解**：可用区就像城市中的不同"变电站"和"网络基站"。如果一个变电站故障，只会影响到它供电的区域，其他区域仍然正常运作。

## 网络规划

### 为什么要网络规划？

- 合理的网络规划可以**避免网段冲突**
- 保障网络的**可扩展性**
- 网络规划不当会导致后期**极高的重建成本**

> **建议**：在创建 VPC 之前先进行网络规划。

### IP 地址规划原则

1. **使用私有地址段**：根据 RFC1918 建议，使用以下私有 IPv4 地址：
   - `10.0.0.0/8`（如 10.0.0.0/16）
   - `172.16.0.0/12`（如 172.16.0.0/16）
   - `192.168.0.0/16`（如 192.168.0.0/24）

2. **网段掩码范围**：16~28 位

3. **不能使用的网段**：
   - `100.64.0.0/10`
   - `224.0.0.0/4`
   - `127.0.0.0/8`
   - `169.254.0.0/16`

4. **避免网段冲突**：多个 VPC 互通时，确保网段不重叠

## 创建专有网络和交换机

### 通过控制台创建

#### 步骤 1：创建专有网络

1. 前往 [VPC 控制台 - 创建专有网络](https://vpc.console.aliyun.com/vpc/cn-hangzhou/vpcs/new)
2. 配置参数：
   - **地域**：选择计划创建云资源的地域（注意：VPC 创建后**不能更改地域**）
   - **IPv4网段**：选择建议的网段，或输入自定义网段
   - **名称**：为 VPC 命名
   - **描述**（可选）：添加说明

#### 步骤 2：创建交换机

1. 在创建 VPC 时，可以同时创建第一个交换机
2. 配置参数：
   - **可用区**：选择需要的可用区（需查看该可用区是否有库存）
   - **IPv4网段**：在 VPC 网段内划分一个子网段
   - **名称**：为交换机命名

3. **建议**：创建多个交换机分布在不同可用区，提高可用性

> **注意**：交换机创建后，其网段**不能修改**。

### 通过 Terraform 创建

```hcl
# 指定创建 VPC 的地域
provider "alicloud" {
  region = "cn-hangzhou"
}

# 获取可用区列表
data "alicloud_zones" "available_zones" {
  available_resource_creation = "VSwitch"
}

# 创建 VPC 
resource "alicloud_vpc" "example_vpc" {
  vpc_name   = "example_vpc_name"
  cidr_block = "10.0.0.0/16"  # 指定网段 
}

# 创建交换机 
resource "alicloud_vswitch" "example_vswitch" {
  vswitch_name = "example_vswitch_name"
  cidblock   = "10.0.0.0/24"
  vpc_id       = alicloud_vpc.example_vpc.id
  zone_id      = data.alicloud_zones.available_zones.zones.0.id
}
```

### 通过 API 创建

```python
# 1. 先创建 VPC
aliyunsdkcore.request.acrequest('CreateVpc', {
    'RegionId': 'cn-hangzhou',
    'CidrBlock': '10.0.0.0/16',
    'VpcName': 'my-vpc'
})

# 2. 再创建交换机
aliyunsdkcore.request.acrequest('CreateVSwitch', {
    'RegionId': 'cn-hangzhou',
    'VpcId': 'vpc-xxx',  # 上一步创建的 VPC ID
    'CidrBlock': '10.0.0.0/24',
    'ZoneId': 'cn-hangzhou-a',
    'VSwitchName': 'my-vswitch'
})
```

## 删除专有网络和交换机

### 删除条件

删除 VPC 或交换机前，需要确保：

1. **交换机删除条件**：
   - 交换机未共享
   - 未绑定自定义路由表和网络 ACL
   - 交换机内的云产品资源已释放

2. **VPC 删除条件**：
   - VPC 内资源已释放完成
   - 已取消与云企业网等网络服务的关联

### 删除顺序

删除时需要按照以下顺序：
1. 先删除交换机
2. 再删除 VPC

## 附加网段

### 什么是附加网段？

当 VPC 的可用 IP 地址数不足时，可以使用**附加网段**扩充地址空间。

- 附加网段与主网段**同时生效**
- 可用于创建交换机、部署 ECS 等云产品资源

### 附加网段限制

- 每个 VPC 默认支持添加 **5 个 IPv4 附加网段** 和 **5 个 IPv6 附加网段**
- 不能使用与主网段重叠的网段
- 不能使用系统保留的网段

### 添加附加网段

1. 在 VPC 基本信息页面，点击**网段管理**页签
2. 选择添加方式：
   - **推荐网段**：快速选择 10.0.0.0/16、172.16.0.0/16 或 192.168.0.0/16
   - **高级配置网段**：自定义网段
   - **IPAM 分配的地址段**：使用 IPAM 管理工具分配

## 预留网段

### 什么是预留网段？

在交换机中预留网段，可以确保此网段**不被其他资源占用**。

- 当前主要用于给弹性网卡的辅助私网 IP 分配 [IP 前缀](https://help.aliyun.com/zh/ecs/user-guide/ip-prefix)
- 预留网段内的 IP 不会自动分配给其他资源

### 预留网段限制

- 每个 VPC 支持创建最多 **100 个 IPv4 预留网段** 和 **100 个 IPv6 预留网段**
- IPv4 掩码长度最大不超过 28
- IPv6 网段掩码长度最大不超过 80
- 预留网段内不能包含系统保留地址

---

## IPv6 支持

### 开启 IPv6

创建 VPC 和交换机时，可以选择开启 IPv6：

1. 选择 **系统分配的 IPv6 地址段**，并选择 **分配 BGP(多线)**
2. 系统将自动创建 IPv6 网关并分配 IPv6 网段

> **注意**：开启 IPv6 后，默认仅支持**私网通信**。如需公网通信，需[开通 IPv6 公网带宽](https://help.aliyun.com/zh/ipv6-gateway/user-guide/enable-and-manage-ipv6-internet-bandwidth)。

## 系统保留地址

交换机网段中存在一些**系统保留地址**，无法分配给云资源。

### IPv4 保留地址

每个交换机的**第 1 个**和**最后 3 个** IP 地址为系统保留地址。

**示例**：
- 交换机网段：`192.168.1.0/24`
- 保留地址：`192.168.1.0`、`192.168.1.253`、`192.168.1.254`、`192.168.1.255`

### IPv6 保留地址

每个交换机的**第 1 个**和**最后 9 个** IP 地址为系统保留地址。

## 默认专有网络与默认交换机

### 什么是默认 VPC？

阿里云可以为每个地域自动创建一个**默认 VPC 和默认交换机**：

- 每个地域只能创建一个默认 VPC
- 每个可用区只能创建一个默认交换机
- 默认 VPC 网段固定为 `172.16.0.0/12`

### 使用场景

- **适合**：快速验证、业务测试
- **不适合**：生产环境、长期网络服务

> **建议**：生产环境建议自定义创建 VPC，根据业务需求进行精细化网络规划。

## 跨账号授权

如果需要跨账号连接 VPC（如通过云企业网 CEN、专线连接），需要先进行跨账号授权。

### 授权步骤

1. 登录 VPC 所属账号
2. 在 VPC 控制台进行跨账号授权
3. 对方账号在创建 VPC 连接时可以选择本账号的 VPC

> **注意**：此处的账号指的是阿里云主账号，而非 RAM 用户（子账号）。
