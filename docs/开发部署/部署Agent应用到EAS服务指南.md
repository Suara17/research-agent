## 前言

### 什么是 EAS 服务？

EAS（Elastic Algorithm Service）是阿里云 PAI 平台提供的模型在线服务，能够将您开发的 Agent 应用部署为可扩展的在线 API 服务。

### 部署流程概览

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│  1. 创建应用     │ -> │  2. 网络配置    │ -> │  3. 部署服务    │ -> │  4. 调用服务    │
│  LangStudio     │    │  VPC + NAT      │    │  EAS            │    │  获取 Endpoint  │
└─────────────────┘    └─────────────────┘    └─────────────────┘    └─────────────────┘
```

### 前提条件

在开始之前，请确保您已完成以下准备：

| 准备项 | 说明 | 获取方式 |
|--------|------|----------|
| 阿里云账号 | 需要有阿里云账号并开通 PAI 服务 | [阿里云官网](https://www.aliyun.com/) |
| 百炼 API-KEY | 用于调用大模型服务 | [百炼控制台](https://bailian.console.aliyun.com/) |
| Agent 应用 | 已完成开发调试的代码型应用 | LangStudio 中创建 |

## 第一步：创建代码型应用

### 1.1 登录 PAI 控制台

1. 打开浏览器，访问 [PAI 控制台](https://pai.console.aliyun.com)
2. 在页面右上方选择目标**地域**（建议选择 **华东1（杭州）**）
   > **注意**：后续所有资源（VPC、EAS 等）都应选择同一地域
3. 在左侧导航栏找到**模型应用**，点击展开后选择**大模型应用开发（LangStudio）**

### 1.2 新建应用

1. 进入目标工作空间后，在**应用**页签点击**新建应用**
2. 在下拉列表中选择**代码模式**

![新建应用示意图](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4663959671/p1049875.png)

3. 在**新建应用**页面填写以下信息：

| 参数 | 说明 | 示例 |
|------|------|------|
| 新建方式 | 选择创建方式 | 选择**从模板新建** |
| 模板 | 选择基础模板 | 选择 **LLM Basic** |
| 名称 | 为应用命名 | `智能问答Agent` |
| 运行时 | 计算环境（必选） | 选择已有运行时或新建 |
| 工作路径 | OSS 存储路径 | 自动填充 |
| 描述 | 应用说明（可选） | `用于测试的智能问答助手` |

> **什么是运行时？**
> 运行时是 LangStudio 提供的云端计算环境，用于在开发阶段执行和调试您的代码。它相当于一个"虚拟的开发电脑"，您可以在这上面运行和测试代码。
> 
> **重要**：运行时仅用于开发调试，与最终部署的 EAS 服务无关。

### 1.3 配置环境变量

为了让您的应用能够调用阿里云百炼的大模型服务，需要配置 API-KEY。

**步骤：**

1. 在 LangStudio 开发页面的项目目录中
2. 在项目根目录创建 `.env` 文件
3. 写入以下内容：

```bash
DASHSCOPE_API_KEY=your-api-key-here
```

**如何获取 API-KEY：**

1. 打开浏览器，访问 [阿里云百炼控制台](https://bailian.console.aliyun.com/)
2. 在左侧导航栏找到 **API-KEY**（或类似名称的菜单）
3. 创建新的 API-KEY 或查看已有的 API-KEY
4. 将获取到的 KEY 复制到 `.env` 文件中

> **注意**：API-KEY 类似于密码，请勿泄露给他人。

### 1.4 调试 Agent

在部署之前，建议先在 LangStudio 中调试您的应用。

**启动调试：**

1. 在开发页面右上方点击**运行**按钮
2. 等待运行时启动（首次可能需要 1-2 分钟）
3. 启动成功后，页面右侧会弹出调试面板

**调试方式：**

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| API 调试 | 直接调用 API 接口测试 | 精确测试单个请求 |
| 对话面板 | 可视化对话界面 | 测试多轮对话 |

**测试示例：**

在 API 调试中选择 `POST /` 接口，发送以下请求：

```json
{
  "question": "你好，请介绍一下自己"
}
```

如果返回了回答，说明应用运行正常。

**查看调试信息：**

- **链路追踪**：查看请求的详细过程，包括 LLM 调用、工具执行等
- **日志**：查看代码运行日志，用于排查错误

## 第二步：网络规划与配置

> **重要**：此步骤是部署成功的关键，请仔细阅读。

### 为什么需要配置网络？

EAS 服务默认是"封闭"的，无法访问公网。但您的 Agent 应用需要调用阿里云百炼的大模型服务，这需要访问公网。因此，我们需要配置 VPC（专有网络）和 NAT 网关来让 EAS 服务能够访问公网。

### 2.1 创建专有网络（VPC）

**概念解释：**
- **VPC（Virtual Private Cloud）**：专有网络，相当于在云上建立自己的私有网络
- **交换机（vSwitch）**：VPC 内的子网，用于划分不同的网络区域

**操作步骤：**

1. 打开浏览器，访问 [VPC 控制台](https://vpc.console.aliyun.com)
2. 确保地域选择与 PAI 相同的地域（如华东1杭州）
3. 点击**创建专有网络**

**配置参数：**

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| 地域 | 选择与 EAS 相同的地域 | 华东1（杭州） |
| IPv4网段 | VPC 的地址范围 | `10.0.0.0/16` |
| 名称 | 给 VPC 起个名字 | `eas-vpc` |

> **网段选择建议**：
> - 使用 RFC1918 私有地址：`10.0.0.0/16`、`172.16.0.0/16` 或 `192.168.0.0/16`
> - 确保与已有 VPC 不重叠

4. 创建交换机（在创建 VPC 时可以同时创建）

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| 可用区 | 选择有库存的可用区 | 如 cn-hangzhou-a |
| IPv4网段 | 交换机地址范围 | `10.0.1.0/24` |
| 名称 | 交换机名称 | `eas-vswitch` |

> **建议**：创建多个交换机在不同可用区，可以提高可用性

### 2.2 创建安全组

**概念解释：**
- **安全组**：相当于"防火墙"，控制进出流量

**操作步骤：**

1. 打开浏览器，访问 [ECS 安全组](https://ecs.console.aliyun.com/securityGroup) 页面
2. 点击**创建安全组**
3. 填写基本信息：
   - **名称**：`eas-sg`
   - **所属地域**：选择与 VPC 相同的地域
   - **所属 VPC**：选择刚才创建的 VPC

4. **配置安全组规则**（重要！）：
   - 默认情况下，出方向允许所有流量，这已经满足我们的需求
   - 如果需要更精细的控制，可以添加出方向规则

### 2.3 配置公网访问（NAT 网关）

> **此步骤仅适用于需要访问公网的情况**。如果您的应用不需要调用公网 API（如调用内网服务），可以跳过此步骤。

**为什么需要 NAT 网关？**
- EAS 服务在 VPC 内只有内网 IP，无法直接访问公网
- NAT 网关可以帮我们将内网请求转发到公网

**操作步骤：**

#### 步骤 1：创建 NAT 网关

1. 访问 [NAT 网关购买页](https://vpc.console.aliyun.com/buy/nat)
2. 选择：
   - **地域**：与 VPC 相同（如华东1杭州）
   - ** VPC**：选择刚才创建的 VPC
3. 购买时会自动创建一个 EIP（弹性公网 IP）

#### 步骤 2：配置 SNAT 条目

1. 在 VPC 控制台找到 **NAT 网关** > **公网 NAT 网关**
2. 找到刚创建的 NAT 网关，点击进入详情
3. 点击 **创建 SNAT 条目**
4. 配置：
   - **SNAT 条目粒度**：选择 **VPC 粒度**
   - 这样该 VPC 内所有发往公网的流量都会通过 NAT 网关

> **什么是 SNAT？** SNAT（Source Network Address Translation）将内网 IP 转换为公网 IP，让内网服务可以访问公网。

#### 步骤 3：检查路由表

1. 在 VPC 控制台点击 **路由表**
2. 选择刚才创建的 VPC
3. 确认存在一条路由：
   - **目标网段**：`0.0.0.0/0`
   - **下一跳**：类型为 **NAT 网关**，指向刚创建的 NAT 网关

如果没有这条路由，需要手动添加。

## 第三步：部署为 EAS 服务

### 3.1 开始部署

1. 回到 LangStudio 开发页面
2. 点击右上角的**部署**按钮

### 3.2 配置部署参数

在部署配置页面，填写以下信息：

| 参数 | 说明 | 示例 |
|------|------|------|
| 服务名称 | EAS 服务的名称 | `my-agent-service` |
| 资源配置 | 选择实例规格 | 根据需求选择 |
| 专有网络 | 选择步骤 2.1 创建的 VPC | `eas-vpc` |
| 交换机 | 选择步骤 2.1 创建的交换机 | `eas-vswitch` |
| 安全组 | 选择步骤 2.2 创建的安全组 | `eas-sg` |

> **重要**：网络配置是必填项，如果不配置，部署后服务将无法访问公网，导致调用大模型失败！

### 3.3 提交部署

1. 检查配置信息是否正确
2. 点击**提交部署**
3. 等待部署完成（通常需要 5-10 分钟）

### 3.4 获取服务访问信息

部署成功后：

1. 点击页面上的**跳转到 EAS**
2. 进入 EAS 服务详情页面
3. 在**概览**页签找到**查看调用信息**
4. 记录以下信息：
   - **访问地址（Endpoint）**：形如 `https://xxx.pai.aliyun.com`
   - **认证 Token**：用于身份验证

## 第四步：调用 EAS 服务

### 4.1 使用 curl 调用

打开终端（Windows 下可使用 CMD 或 PowerShell），运行以下命令：

```bash
curl -X POST 'https://your-endpoint.pai.aliyun.com' \
  -H 'Authorization: Bearer your-token' \
  -H "Content-Type: application/json" \
  -d '{"question": "北京今天的天气如何？"}'
```

**请替换以下内容：**
- `your-endpoint.pai.aliyun.com`：替换为您获取的访问地址
- `your-token`：替换为您的认证 Token

### 4.2 使用 Python 调用

```python
import requests

url = "https://your-endpoint.pai.aliyun.com"
headers = {
    "Authorization": "Bearer your-token",
    "Content-Type": "application/json"
}
data = {
    "question": "北京今天的天气如何？"
}

response = requests.post(url, headers=headers, json=data)
print(response.json())
```

### 4.3 查看服务监控

在 EAS 服务详情页面可以查看：
- 请求次数
- 响应时间
- 错误率
- 链路追踪信息

## 第五步：费用与成本管理

> **重要**：请务必阅读此部分，了解部署 EAS 服务涉及的费用，避免产生意外账单。

### 5.1 费用构成概览

部署 EAS 服务可能涉及以下费用：

| 资源 | 是否必需 | 计费方式 | 大致费用（元/天） |
|------|----------|----------|------------------|
| EAS 计算资源 | 是 | 按量付费 | 约 10-100+ |
| NAT 网关 | 公网访问必需 | 按量付费 | 约 2-20 |
| EIP | NAT 网关必需 | 按量付费 | 约 1-10 |
| VPC | 是 | 免费 | 0 |
| 安全组 | 是 | 免费 | 0 |

### 5.2 EAS 计算资源费用

EAS 提供两种计费模式：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **按量付费** | 按运行时长计费，按分钟计算 | 测试、需求波动大 |
| **包年包月** | 预付费，价格更优惠 | 长期稳定业务 |

**按量付费定价参考**：

- CPU：约 0.194 元/核/小时
- 内存：约 0.024 元/GB/小时

**示例**：2 核 CPU + 8 GB 内存，运行 8 小时：

```
费用 = 2 × (2 × 0.194 + 8 × 0.024) × 8 ≈ 46.4 元/天
```

### 5.3 网络费用

如果您需要公网访问（调用百炼大模型），还需要支付网络费用：

| 资源 | 计费说明 |
|------|----------|
| **NAT 网关** | 实例费 0.23 元/小时 + 流量费（按处理流量） |
| **EIP** | 按固定带宽或流量计费 |

### 5.4 免费额度

| 资源 | 免费额度 |
|------|----------|
| 系统盘（公共资源） | 30 GB |
| 系统盘（专属资源） | 200 GB |
| 共享网关 | 免费 |

### 5.5 成本优化建议

#### ⚠️ 最重要：及时停止服务！

> 按量付费模式下，只要服务处于「运行中」状态就会持续计费，即使没有任何请求也会收费！

**正确做法**：
- 测试完成后，**立即停止服务**
- 在 EAS 控制台服务列表中，点击「停止」按钮

#### 其他优化建议

1. **选择合适的计费模式**
   - 短期测试：按量付费
   - 长期业务：包年包月

2. **使用节省计划**
   - 适合有稳定用量的用户
   - 可以享受折扣优惠

3. **公网流量优化**
   - 模型文件上传到同地域 OSS
   - 部署时直接挂载，避免公网流量

4. **选择合适的实例规格**
   - 根据实际需求选择，避免资源浪费
   - CPU 推理无需使用 GPU

### 5.6 查看账单

1. 登录阿里云控制台
2. 进入「费用与成本」→「账单详情」
3. 可以按产品筛选查看具体费用

## 常见问题排查

### 问题 1：部署后服务无法调用大模型

**症状**：调用服务返回错误，或者没有响应

**排查步骤：**

1. **检查网络配置**
   - 确认部署时选择了正确的 VPC 和交换机
   - 确认配置了 NAT 网关

2. **检查 SNAT 条目**
   - 确认 SNAT 条目中的交换机与部署时指定的交换机一致

3. **检查路由表**
   - 确认有 `0.0.0.0/0` 指向 NAT 网关的路由

4. **检查安全组**
   - 确认安全组出方向允许公网访问

**快速验证方法：**

在服务配置的启动命令中添加测试指令：

```bash
curl -I -A "Mozilla/5.0" --connect-timeout 5 https://www.aliyun.com
```

部署后查看日志，如果返回 `200` 说明公网正常。

---

### 问题 2：无法内网访问其他云服务

**排查步骤：**

1. 确认 EAS 服务与其他服务在同一 VPC
2. 检查安全组出方向规则
3. 确认目标服务已添加 EAS 所在交换机网段到白名单

---

### 问题 3：服务创建或扩容失败

**原因**：交换机 IP 地址不足

**解决方案**：

规划足够的 IP 地址数量：

```
所需 IP 数 = 稳定运行实例数 + 滚动更新额外实例数 + 预留缓冲
```

建议使用 `/24` 或更大的网段，确保 IP 充足。
